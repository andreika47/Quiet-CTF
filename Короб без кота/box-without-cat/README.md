# Короб без кота

В защищённом хранилище используется обратимая подпрограмма `VaultKDF`. Её
наивная Qualtran-декомпозиция корректна, но не помещается в доступный
fault-tolerant бюджет. Оптимизируйте схему, сохранив её действие вместе с
относительными фазами.

Вам разрешены только гейты `X`, `CX`, `T` и `T†`. Сервер принимает JSON,
проверяет схему на всех базисных состояниях, запускает принятую схему через
qsim и использует результат для расшифровки флага.

## Материалы

- `challenge/bloqs.py` — `VaultKDF` как Qualtran `Bloq`;
- `challenge/circuit.py` — наивная последовательность операций;
- `challenge/resources.py` — ресурсная модель и лимиты;
- `challenge/client.py` — клиент отправки решения;
- `generate_circuit.py` — запись наивной схемы в `circuit.json`.


Посмотреть декомпозицию и стоимость:

```bash
docker compose build
docker compose run --rm challenge
```

## Формат решения

Схема — это список операций на 12 кубитах. Кубиты `0..9` образуют little-endian
data-регистр, `10..11` — чистые анцилла: в конце они должны снова быть `|0⟩`.
В посылке допустимы только `x`, `cx`, `t` и `tdg`. У `x`, `t` и `tdg` один
кубит. У `cx` два разных: первый — контрольный кубит, второй — целевой кубит.

```json
{
  "n_qubits": 12,
  "operations": [
    {"gate": "x", "qubits": [0]},
    {"gate": "cx", "qubits": [0, 1]},
    {"gate": "t", "qubits": [1]},
    {"gate": "tdg", "qubits": [2]}
  ]
}
```

`n_qubits` всегда `12`. Точные лимиты возвращает `GET /challenge`.

`generate_circuit.py` записывает в `circuit.json` наивную схему из
`naive_program()`: те же `ccx`, `add`, `sub` и фазовые гаджеты. У `add` и
`sub` в операции есть поле `value`. Сервер такой файл не примет: перед
отправкой оставьте только `x`, `cx`, `t` и `tdg`.

Фазовый член по чётности маски собирает `parity_gadget` из `challenge/circuit.py`.
Последний индекс маски — кубит, на который ставятся `T` или `T†`. Положительный
коэффициент даёт `T`, отрицательный — `T†`, модуль коэффициента — число повторов.

Compose монтирует этот каталог в контейнер:

```bash
docker compose run --rm challenge python generate_circuit.py
```

Отправка собранной схемы (можно отправить и через `curl`):

```bash
docker compose run --rm challenge python -m challenge.client circuit.json --url http://host.docker.internal:8000
```
