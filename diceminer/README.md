# diceminer
**DiceCTF 2026**

Дан веб-сервис, реализующий игру, где нужно копать шахты и получать за это монеты. Цель игры — заработать 1 000 000 монет и купить флаг.
В сервисе есть несколько API:
```
POST /api/register    # зарегистрироваться
POST /api/start       # выбрать стартовую позицию
POST /api/move        # передвижение
POST /api/dig         # копать шахту
POST /api/buy         # купить новую кирку или флаг
GET  /api/state       # получить инфо о мире и игроке
```
В игре есть следующие ограничения:
1. Есть 4 типа блоков, каждый из которых дает фиксированное число монет
2. Для добычи дорогих блоков необходимо иметь дорогую кирку
3. На добычу накладываетс налог 95% (то есть мы получаем лишь 5%)

При анализе кода можно заметить, что тип блока определяется детерминированной функцией генерации:
```
function getBlockType(x, y) {
  if (y >= 1) return 'sky';
  if (y === 0) return 'surface';

  const hash = crypto.createHash('md5').update(`${WORLD_SEED}:${x}:${y}`).digest();
  const roll = hash.readUInt32BE(0) / 0xFFFFFFFF;

  if (y <= -50 && roll < 0.04) return 'diamond';
  if (y <= -30 && roll < 0.10) return 'gold';
  if (y <= -15 && roll < 0.20) return 'iron';
  if (y <= -1  && roll < 0.35) return 'coal';
  return 'stone';
}
```
Где `WORLD_SEED` - захардкожен и равен `42`. Таким образом мы можем заранее рассчитать всю карту и понять, где расположены самые дорогие блоки.

Другим важным наблюдением является вычисление заработка в `/api/dig`:
```
let dx = 0, dy = 0;
if (direction === 'left') dx = -1;
if (direction === 'right') dx = 1;
if (direction === 'down') dy = -1;
if (direction === 'up') dy = 1;

let mined = {};
let earnings = 0;
let cx = user.x;
let cy = user.y;
let remaining = pickaxe.range;

while (remaining > 0) {
    cx += dx;
    cy += dy;

    if (cy > 0) break;

    const key = cx + ',' + cy;

    if (user.mined[key]) {
      remaining--;
      continue;
    }

    const blockType = getBlockType(cx, cy);
    const ore = ORES[blockType];
    if (!ore) break;

    if (ore.tier > pickaxe.tier) break;

    mined[key] = true;
    earnings += ore.reward;

    remaining--;
  }

const blocks = Object.keys(mined);
```

Координата блока вычисляется как сумма текущей координаты игрока и смещения, зависящего от "мощности" кирки. Логично попробовать поставить игрока на число, которое соответствует `MAX INTEGER` в JavaScript и посмотреть, что произойдет. Максимальное целое число в JS: `2^53 − 1 = 9007199254740991`. На самом деле - это максимальное целое число, которое JS может хранить точно. Если же пытаться увеличить переменную со значением `9007199254740991` мы получим следующую последовательность:
```
9007199254740991 + 1 = 9007199254740992
9007199254740992 + 1 = 9007199254740992
```
Таким образом, если игрок стоит на координате `x = 9007199254740991` и копает вправо, то при рассчете заработка `earnings` будет учитываться только тип ближайшего блока к игроку блока.
При этом при рассчете налогов сумма заработка считается иначе:
```
let haulBase = 0;
for (const key of blocks) {
const [bx, by] = key.split(',').map(Number);
const ore = ORES[getBlockType(bx, by)];
haulBase += ore.reward;
}
const cost = Math.floor(haulBase * HAULING_RATE);
const net = earnings - cost;

user.energy -= 1;

for (const key of blocks) {
user.mined[key] = true;
}
```
Так как `cx` не будет изменяться из-за переполнения целого числа, а `cy` не меняется, так как мы копаем вправо, то `key = cx + ',' + cy` в `blocks` будет всего один и только он будет облагаться налогом. Таким образом нам нужно написать скрипт для быстрого фарма монет с использованием описанной выше схемы ухода от налогов. Примерный алгоритм скрипта:
1. Зарегистрировать пользователя и задать ему начальную координату `x = 9007199254740991`
2. Копать вниз и вправо, пока не получим самую лучшую кирку, которая может добывать алмазные блоки
3. Вычисляем такие значения `y`, где на `x = 9007199254740991 + 1` находится алмазный блок
4. В цикле доходим до этого места, копаем вправо, пока не получим заветный миллион монет
