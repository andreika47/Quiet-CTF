# plane-or-exchange
**DiceCTF 2026**

Дана реализация протокола Диффи-Хеллмана на основе группе кос с использованием многочлена Александера в качестве инварианта узлов. При анализе реализации протокола можно выявить следующие важные места:
1. Точка - это пара перестановок `(x, o)`, для которой `compose(x, inverse(o))` — один цикл без неподвижных точек. С помощью таких точек кодируются диаграммы узлов.
2. `calculate()` вычисляет инвариант узла (многочлен Александера) через лемму Линдстрёма–Гесселя–Вьенно (LGV): на основе переечения путей строится матрица переходов, и вычисляется её определитель `Δ(K)`, где `K` - узел.
3. `scramble()` применяет движения, похожие на движения Рейдемейстера `(slide1, slide2, shuffle)`. Они меняют представление косы, но сохраняют тип узла (а значит, и инвариант).
4. `connect(A, B)` соединяет две косы, обменивая последнюю прядь `A` с первой прядью `B` — это связная сумма узлов.

Шаги получения общего ключа ниже:
```
# Алиса и Боб соединяют свои закрытые ключи с общим открытым ключом и перемешивают полученную косу. Таким образом каждая из сторон получает свой собственный открытый ключ.
alice_pub = scramble(connect(public_info, alice_priv))    
bob_pub   = scramble(connect(public_info, bob_priv))

# обший закрытый ключ вычисляется как соединение открытого ключа собеседника и своего закрытого ключа
shared = normalize(
    calculate(connect(alice_priv, bob_pub))
)
```

Уязвимость данной реализации заключается в том, что многочлен Александера является мультипликативным инвариантом, то есть:
```math
Δ(K_1 \# K_2) = Δ(K_1) * Δ(K_2)
```
Поскольку `scramble()` сохраняет тип узла, то
```math
Δ(alice\_pub) = Δ(public\_info) * Δ(alice\_priv)
Δ(alice\_priv) = Δ(alice\_pub) / Δ(public\_info)
```
и аналогично
```math
Δ(bob\_pub) = Δ(public\_info) * Δ(bob\_priv)
Δ(bob\_priv) = Δ(bob\_pub) / Δ(public\_info)
```
А значит общий закрытый ключ можно вычислить как
```math
shared = Δ(alice\_priv) * Δ(bob\_pub) = Δ(alice\_pub) / Δ(public\_info) * Δ(bob\_pub)
```
где нам известны все три значения.
